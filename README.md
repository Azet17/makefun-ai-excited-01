A giant koi bursts out of a curling night wave above a neon city — and instead of
falling back, it keeps climbing, its leap scattering droplets that turn into stars
mid-air. Water breaking its own rule: the smallest drops become the brightest
lights, with one golden koi flying against the dark. Behind it a full moon hangs
low over lit windows and a glowing horizon, while the wave curls into an arch of
foam under the leap. The image is drawn entirely by `main.ts` (own PNG encoder,
seeded random only, no copied pixels), so every run produces the exact same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
